# 🧠 JARK GPT – Intelligent Medical & Science Q&A System

JARK GPT is an AI-powered **web-based Q&A system** designed for medical and science students.  
It provides **instant, accurate, and exam-focused answers** using a hybrid system of a **custom knowledge base + AI fallback (GPT-4o-mini)**.

---

## 🎯 Purpose

The main goal of JARK GPT is to help students:
- Get fast and reliable answers
- Revise efficiently for exams
- Reduce dependency on long web searches or textbooks
- Learn through structured, concise responses

It is especially useful for **medical entrance exam preparation**.

## 🏗️ System Architecture

Hybrid AI System:

- 📚 Custom Knowledge Base (JARK EDUCATION)
- 🤖 AI Fallback (OpenAI GPT-4o-mini)
- 🧠 Intent Detection (Question understanding & classification)

---

## 🔄 How It Works

1. User enters a question in the web interface
2. System checks internal knowledge base
   - If found → returns answer with **JARK EDUCATION source**
   - If not found → sends query to AI (GPT-4o-mini)
3. Intent detection classifies question type:
   - Definition
   - Explanation
   - General query
4. AI generates structured response:
   - Science topics → 5–8 lines structured answer
   - General topics → 1–2 line concise answer
5. Output is displayed with proper source label:
   - JARK EDUCATION or Generated by AI
